## Descripción
Portfolio personal desarrollado con conceptos aprendidos en clase

## Tecnologías utilizadas
* React + Vite
* CSS3

## Cómo ejecutar el proyecto localmente
1. Clonar el repositorio: `git clone https://github.com/TomyCano/Portafolio-react-tp1`
2. Instalar dependencias: `npm install`
3. Iniciar el servidor: `npm run dev`
